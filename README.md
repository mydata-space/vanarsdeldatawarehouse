# 📖  Full Data Warehouse, ETL, Analytics and BI Project
Welcome to the Full Data Warehouse, ETL, Analytics and BI report Project repository!
This project highlights industry best practices in data engineering and data analysis, loads over 7.4 millions of rows data 
from two sources (CRM and ERP) demonstrating a comprehensive understanding and strong SQL server coding skills 
on build full modern datawarehouse archicture, performing ETL, advanced analytics and Power BI vizs.

***

## :books: Project Overview 
This project involves:

1. Data Architecture: Designing a Modern Data Warehouse Using Medallion Architecture Bronze, Silver, and Gold
layers.
2. ETL Pipelines: Extracting, transforming, and loading data from source systems into the warehouse.
3. Data Modeling: Developing fact and dimension tables optimized for analytical queries and reports.
4. Dashbord: Developing manufacturer Power BI reports.

## 🎯Project Requirements

I. Warehouse (Data Engineering) specifications

Objective :
Develop a modern data warehouse using SQL Server to consolidate and prepare data for analytics and reporting.

Specifications
1. Data Sources: Import data from two source systems (ERP and CRM) provided as CSV files.
2. Data Quality: Cleanse and resolve data quality issues.
3. Integration: Combine both sources into a single, user-friendly data model.
4. Scope: Focus on the latest dataset only; historization of data is not required.
5. Documentation: Provide clear documentation of the data model for BI users.

II. Power BI Data Anlyst Specifications

Objective :
Develop a modern Power BI report to track the vendors performance and refresh data weekly.

1. Import Mode: Import data from SQL Server (dimension manufacturers, dimension products, dimension locations and fact sales).
2. Data Modeling: Create start schema model and date dimension  for time intelligence analysis
3. Report : create one page manufactureres report sales overview using Power BI.
